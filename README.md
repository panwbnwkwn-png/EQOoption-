# EQOOption — واجهة أولية

واجهة أمامية تجريبية مستوحاة من لقطات الشاشة التي أرسلها المستخدم. تعمل دون خادم خلفي.

## التشغيل
- افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً من هذا المجلد مثل `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## الموجود حالياً
- مخطط TradingView Advanced Chart مدمج (الرمز الافتراضي OANDA:EURUSD) مع أدوات الرسم والمؤشرات والأطر الزمنية المتاحة في الودجت. أزرار صعود/هبوط ما زالت تجريبية وغير متصلة بسوق حقيقي.
- تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور.
- الملف الشخصي، واجهة الإيداع التجريبية، الدعم، السجل، وصفحة المزيد.
- تبديل اتجاه العربية/الإنجليزية (النصوص الإنجليزية ما زالت جزئية).
- تصميم متجاوب للهواتف والشاشات الأكبر.

## حدود النسخة
لا يوجد نظام حسابات أو قاعدة بيانات أو تنفيذ تداول أو إيداع أو سحب حقيقي. لا تدخل كلمات مرور أو بيانات دفع حقيقية. قبل الإطلاق يلزم بناء API آمن، والتحقق من الهوية، وإدارة الجلسات، ومزود دفع مرخص، وضوابط الامتثال والمخاطر.


## TradingView ومصدر الأسعار
- يتم تحميل مخطط Advanced Chart الرسمي من TradingView عبر سكربت التضمين الخاص به.
- الرمز الافتراضي `OANDA:EURUSD` هو بيانات الفوركس من OANDA على TradingView، وليس زوج OTC خاصاً بـ EQOOption.
- لا تُعرض سيولة/عمق سوق (Order Book) مخصص للمنصة من هذا المخطط وحده. يلزم مزود بيانات يدعم ذلك.
- إذا كان المطلوب شارتاً مطابقاً تماماً ومتصلاً ببيانات OTC الداخلية، فذلك يتطلب ترخيص/إتاحة TradingView Charting Library أو Trading Platform مع Datafeed خاص مرخص ومطابق لمصدر الأسعار.
- يحتاج التضمين إلى اتصال إنترنت، وقد تتأثر الرموز والبيانات بتغطية TradingView وشروط مزودي البيانات.

## موصل بيانات OANDA (جاهز للإعداد، وليس مفعلاً بعد)
أُضيف خادم وسيط يحفظ رمز OANDA على الخادم ولا يكشفه للمتصفح:
- `GET /api/health` للتحقق من إعداد الاتصال.
- `GET /api/oanda/candles?instrument=EUR_USD&granularity=S5&count=500` لجلب شموع تاريخية/حديثة.
- `GET /api/oanda/stream?instruments=EUR_USD` لبث الأسعار عبر Server-Sent Events.

### التفعيل
1. أنشئ حساب OANDA v20 مؤهلاً وفعّل API access من بوابة الحساب، ثم أنشئ Access Token.
2. انسخ `.env.example` إلى `.env` وضع `OANDA_ACCOUNT_ID` و`OANDA_ACCESS_TOKEN`.
3. ابدأ بـ `OANDA_ENV=practice` للاختبار. لا تستخدم `live` إلا بعد التحقق من الترخيص والاختبارات.
4. شغّل `npm start` وافتح `http://localhost:3000/api/health`.

**مهم:** هذا الموصل لا يفعّل الأسعار الحية حتى توضع بيانات حساب صالحة، ولا ينفذ صفقات. بث OANDA يرسل بحد أقصى 4 تحديثات/ثانية لكل أداة، وليس كل tick. كما أن أسعار OANDA ليست أسعار OTC الخاصة بـ EQOOption.

### توصيله بشارت TradingView
الودجت المضمّن حالياً في `index.html` يجلب بياناته من مزود TradingView ولا يقبل تمرير هذا الـ API إليه كـ Datafeed مخصص. لعرض بيانات OANDA داخل مكتبة TradingView Advanced Charts نفسها، يجب أولاً الحصول على موافقة الوصول إلى المكتبة الخاصة من TradingView، ثم تنفيذ Datafeed API وربطه بنقاط `/api/oanda/candles` والبث. لا تُضمّن رمز OANDA في المتصفح مطلقاً.
